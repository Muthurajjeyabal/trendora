# Trendora – Premium Ecommerce Website

**Discover. Shop. Enjoy.**

Premium online store for trending gadgets and everyday products in India.

**Live Domain:** trendora.jmrapps.com

## Features

- Premium modern design (white + black + orange accents)
- Fully responsive (mobile, tablet, desktop)
- Product listing, product detail page
- Shopping cart (add, remove, quantity update)
- Checkout page (Cash on Delivery + WhatsApp order)
- Floating WhatsApp support button
- Admin panel to manage products & orders
- Indian Rupees (₹)
- LocalStorage based (no backend required)

## Pages

| Page | File | Description |
|------|------|-------------|
| Homepage | `index.html` | Hero, Trending, Categories, Best Sellers |
| Product Detail | `product.html` | Gallery, price, features, add to cart |
| Cart | `cart.html` | View & edit cart |
| Checkout | `checkout.html` | Customer details + payment options |
| Admin | `admin.html` | Manage products & orders |

## How to Run Locally

1. Download / clone this repository
2. Open `index.html` in any browser
   - Or use a local server (recommended):
     ```bash
     # Using Python
     python -m http.server 8000
     ```
3. Visit `http://localhost:8000`

## Deploy to GitHub Pages

1. Push this repository to GitHub
2. Go to **Settings → Pages**
3. Source: Deploy from branch → `main` → `/ (root)`
4. Your site will be live at `https://yourusername.github.io/trendora`
